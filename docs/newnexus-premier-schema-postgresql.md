# NewNexus

## Premier schema PostgreSQL V1

Date: 2026-04-29
Statut: proposition technique de travail

## 1. Objet

Ce document traduit le cadrage `NewNexus` en premier schema PostgreSQL exploitable.

Objectifs:

- definir les tables minimales V1
- fixer les colonnes essentielles
- poser les contraintes principales
- preparer une implementation propre via EF Core PostgreSQL

Ce schema couvre:

- securite
- utilisateurs
- societes
- analytiques
- exploitations
- salaries
- tiers
- materiels
- interfaces

## 2. Conventions generales

### 2.1 Nommage

Convention recommandee:

- noms de tables au singulier technique clair ou au pluriel stable, mais de facon uniforme
- schemas PostgreSQL separes si utile, sinon schema `public` en V1
- noms de colonnes en `PascalCase` cote code, mappes en `snake_case` cote PostgreSQL si on suit la convention Npgsql

Pour simplifier V1, recommandation:

- tables dans `public`
- mapping EF Core explicite

### 2.2 Clefs techniques

Toutes les tables principales possedent une clef primaire technique:

- type recommande: `integer generated by default as identity`

### 2.3 Dates

Dates recommandees:

- `timestamp with time zone` pour les dates techniques / horodatages
- `date` pour les dates metier pures sans heure

### 2.4 Activation / desactivation

Quand l'entite le justifie, utiliser:

- `is_active boolean not null default true`

### 2.5 Valeurs codees

Les statuts et types simples peuvent etre stockes en `text` avec contrainte `check` en V1.

Cela evite d'introduire trop tot des enums PostgreSQL si le modele doit encore evoluer.

## 3. Securite

## 3.1 Table `security_module`

But:

- catalogue des modules geres par le systeme de droits

Colonnes:

- `security_module_id integer primary key generated by default as identity`
- `code text not null`
- `label text not null`
- `navigation_group text not null`
- `display_order integer not null default 0`
- `is_active boolean not null default true`
- `created_at_utc timestamp with time zone not null default now()`
- `updated_at_utc timestamp with time zone not null default now()`

Contraintes:

- unique sur `code`
- `navigation_group` non vide

Exemples V1:

- `PARAMETRES`
- `SECURITE`
- `INTERFACES`
- `OUTILS`
- `CONTRAVENTIONS`
- `CARTE_CHARGEMENT_DECHARGEMENT`
- `INDICATEURS_CONDUCTEURS`
- `INDICATEURS_TRACTEURS`

- droits d'un profil par module

## 14. Decisions simples d'implementation

Recommandations pour la future implementation EF Core:

- utiliser une configuration Fluent API explicite
- ne pas compter sur les conventions pour les checks et unicity
- gerer `updated_at_utc` cote application dans un premier temps
- creer un seed minimal pour modules, profils standards et connecteurs d'interface
