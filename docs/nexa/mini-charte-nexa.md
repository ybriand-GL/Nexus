# Mini-charte Nexa

Nexa est la sous-identite IA de Nexus. Elle reprend l'univers sombre, premium et dore de Nexus, avec un accent bleu reserve aux usages d'assistance, de conversation et d'intelligence artificielle.

## Palette

| Usage | Couleur |
| --- | --- |
| Fond principal | `#0B0B0F` |
| Fond secondaire | `#151821` |
| Surface sombre | `#1D202A` |
| Dore principal | `#D7A449` |
| Dore clair | `#F2D28A` |
| Dore pale | `#FFF0C9` |
| Bleu IA | `#2EA8FF` |
| Bleu lumineux | `#4CC2FF` |
| Texte principal | `#F5F7FA` |
| Texte secondaire | `#A7AAB4` |
| Bordure | `#2A2D36` |

Les variables applicatives sont disponibles dans `NewNexus.Web/src/styles/nexa-theme.css` et la version exportable dans `NewNexus.Web/public/nexa/nexa-tokens.css`.

## Logo

- Utiliser `nexa-logo-horizontal-dark.svg` sur fond sombre.
- Utiliser `nexa-logo-horizontal-light.svg` sur fond clair.
- Utiliser `nexa-icon-dark.svg` pour l'avatar, le bouton flottant, les badges et les modules IA sur fond sombre.
- Utiliser `nexa-icon-light.svg` uniquement sur fond clair.
- Conserver une zone de respiration minimale equivalente a 25% de la hauteur du symbole autour du logo.
- Taille minimale conseillee: 32 px pour le symbole seul, 140 px de large pour la version horizontale.

## Usages autorises

- Bouton "Demander a Nexa".
- En-tete du panneau de discussion.
- Avatar de message assistant.
- Badges IA, source interne, reponse validee et connaissance Nexa.
- Administration Nexa, base de connaissance et tickets issus de Nexa.

## Interdictions

- Ne pas remplacer le logo Nexus par le logo Nexa dans la navigation generale.
- Ne pas recolorer Nexa avec une palette sans bleu.
- Ne pas utiliser le bleu comme couleur principale de Nexus.
- Ne pas deformer le symbole ou separer le N de la bulle.
- Ne pas ajouter d'effets neon lourds ou d'animations permanentes.

## Exemple UI

Dans Nexus, Nexa s'exprime via une couche dediee: bouton flottant avec halo bleu discret, panneau sombre a bordures fines, bulles assistant avec accent bleu, bulles utilisateur plus neutres, badges de fiabilite et sources internes.
