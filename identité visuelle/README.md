# Nexus — Brand handoff pour intégration web

Direction retenue : **Concept 4C**.

Ce paquet contient les éléments de référence pour intégrer l’identité visuelle Nexus dans une application web.

## Contenu

- `00_reference/` : logos initiaux fournis.
- `01_concepts/` : variantes visuelles, dont `concept_4c_selected.png`.
- `02_brand_guides/` :
  - `nexus_brand_kit.png`
  - `nexus_icon_favicon_kit.png`
  - `nexus_web_ui_style.png`
- `03_assets/svg/` : versions SVG simplifiées prêtes à intégrer ou à retravailler.
- `03_assets/png/` : icônes PNG aux tailles courantes + `favicon.ico`.
- `04_codex/` :
  - `design-tokens.json`
  - `design-tokens.css`
  - `index-preview.html`
  - `codex_integration_prompt.md`

## Palette

- Navy : `#0B1E75`
- Gold : `#F7B500`
- Orange : `#FF8A00`
- Purple : `#6C3DFF`
- Cyan : `#18BCEB`
- Green : `#24B05A`

## Typographies recommandées

- Titres : **Sora Bold**
- Interface / corps : **Inter Regular**

## Attention

Les images de concept servent de référence graphique premium. Les SVG fournis sont des versions techniques simplifiées pour démarrer l’intégration. Pour une identité définitive juridiquement et graphiquement parfaite, refaire le logo final en vectoriel professionnel reste préférable.
